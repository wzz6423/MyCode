``` mermaid
%% Service Architecture
graph TD
    subgraph Server Startup
        A[加载配置文件] --> B[初始化数据管理器]
        B --> C[启动热点管理线程]
        C --> D[启动HTTP服务器]
    end

    subgraph Client Request
        D --> E{请求类型}
        E -->|上传文件| F[保存到备份目录]
        F --> G[创建BackupInfo]
        G --> H[更新数据表]
        E -->|文件列表| I[生成HTML页面]
        E -->|文件下载| J{是否压缩?}
        J -->|是| K[解压文件]
        K --> L[更新备份状态]
        J -->|否| M[直接传输]
    end

    subgraph Hot Management
        C --> N[定期扫描备份目录]
        N --> O{文件存在?}
        O -->|是| P{超过热点时间?}
        P -->|是| Q[创建压缩包]
        Q --> R[删除原文件]
        R --> S[更新备份状态]
        P -->|否| N
        O -->|否| N
    end

    subgraph Data Persistence
        H --> T[JSON序列化]
        S --> T
        T --> U[备份文件存储]
        U -->|启动时| B
    end

    style A fill:#BBDEFB,stroke:#2196F3
    style B fill:#C8E6C9,stroke:#4CAF50
    style C fill:#FFE0B2,stroke:#FB8C00
    style D fill:#F8BBD0,stroke:#E91E63
    style Q fill:#FFCDD2,stroke:#F44336
    style T fill:#D1C4E9,stroke:#673AB7

```

``` mermaid

graph LR
    Start((开始)) --> Config[加载配置]
    Config --> DataMgr[初始化数据管理器]
    DataMgr --> HotThread[启动热点管理]
    HotThread --> HTTPServer[启动HTTP服务]
    HTTPServer --> Upload[文件上传]
    HTTPServer --> List[文件列表]
    HTTPServer --> Download[文件下载]
    HotThread --> Scan[扫描目录]
    Scan --> CheckTime{超过热点时间?}
    CheckTime -->|是| Compress[压缩文件]
```
