汇编语言是直接对应机器指令的低级编程语言，其语法与CPU架构（如x86、ARM、MIPS等）强相关。本文以**x86架构**（最常用）和**NASM汇编器**（语法简洁）为例，详细介绍汇编语言的语法规则及实例。


### 一、汇编语言基本概念
- **核心作用**：将人类可读的指令转换为机器码（二进制），直接控制硬件。
- **架构依赖**：不同CPU架构（如x86、ARM）的汇编语法差异极大，本文聚焦x86。
- **汇编器**：将汇编代码转换为机器码的工具（如NASM、GAS），本文以NASM为例。


### 二、语法基本构成
汇编代码的核心组成包括**指令**、**操作数**、**伪指令**和**注释**，结构清晰。


#### 1. 指令格式
汇编指令由**操作码**（指令功能）和**操作数**（操作对象）组成，基本格式：  
`操作码 [操作数1], [操作数2], ...`  
- 操作码：表示具体操作（如`mov`传送数据、`add`加法）。  
- 操作数：指令的操作对象，数量根据指令而定（0个、1个或2个）。  


#### 2. 操作数类型
操作数是指令的核心，x86中主要有3类：

| 类型       | 说明                                  | 示例                          |
|------------|---------------------------------------|-------------------------------|
| 立即数     | 直接给出的常数（十进制/十六进制等）   | `10`（十进制）、`0x1A`（十六进制） |
| 寄存器     | CPU内部的存储单元（如`ax`、`ebx`）    | `ax`（16位）、`eax`（32位）     |
| 内存地址   | 内存中的存储单元（需通过地址访问）    | `[0x1234]`、`[bx+si]`          |


#### 3. 伪指令（Directives）
伪指令是汇编器识别的辅助指令，不对应机器码，用于告诉汇编器如何处理代码（如定义数据、划分段）。常见伪指令：

| 伪指令 | 作用                          | 示例                                  |
|--------|-------------------------------|---------------------------------------|
| `db`   | 定义1字节数据（byte）         | `num db 5`（定义1字节变量`num`，值为5） |
| `dw`   | 定义2字节数据（word）         | `val dw 0x1234`（定义2字节变量`val`） |
| `dd`   | 定义4字节数据（double word）  | `float dd 3.14`（定义4字节浮点数）    |
| `section` | 划分程序段（如数据段、代码段） | `section .data`（数据段）、`section .text`（代码段） |
| `global` | 声明全局符号（如程序入口）     | `global _start`（声明`_start`为入口）  |


#### 4. 注释
用`;`开头，用于说明代码功能，汇编器会忽略注释内容。  
示例：  
```nasm
mov ax, 10  ; 将立即数10传送到ax寄存器
```


### 三、寻址方式
寻址方式是汇编语言的核心难点，决定了如何访问操作数（尤其是内存）。x86支持多种寻址方式：


#### 1. 立即寻址
操作数是常数，直接嵌入指令中。  
格式：`操作码 目标, 立即数`  
示例：  
```nasm
mov ax, 0x100  ; 将十六进制数0x100传送到ax寄存器
add bx, 5      ; bx = bx + 5
```


#### 2. 寄存器寻址
操作数是寄存器，直接访问CPU内部寄存器。  
格式：`操作码 目标寄存器, 源寄存器`  
示例：  
```nasm
mov ax, bx    ; 将bx的值传送到ax（ax = bx）
add cx, dx    ; cx = cx + dx
```


#### 3. 直接寻址
操作数是内存地址，直接通过地址访问内存。  
格式：`操作码 目标, [内存地址]`  
示例：  
```nasm
; 假设内存地址0x2000处存储值为20
mov ax, [0x2000]  ; ax = 内存0x2000处的值（即20）
```


#### 4. 寄存器间接寻址
通过寄存器中的值作为内存地址访问内存（寄存器间接指向内存）。  
格式：`操作码 目标, [寄存器]`  
示例：  
```nasm
mov bx, 0x2000    ; bx = 0x2000（地址）
mov ax, [bx]      ; ax = 内存0x2000处的值（通过bx间接访问）
```


#### 5. 基址+变址寻址
通过“基址寄存器+变址寄存器”计算内存地址（常用于数组访问）。  
x86中基址寄存器：`bx`、`bp`；变址寄存器：`si`、`di`。  
格式：`操作码 目标, [基址寄存器 + 变址寄存器]`  
示例：  
```nasm
mov bx, 0x3000    ; 基址：数组起始地址0x3000
mov si, 2         ; 变址：数组索引（每个元素占2字节）
mov ax, [bx + si] ; ax = 内存(0x3000 + 2)处的值（数组第1个元素）
```


#### 6. 带位移的基址+变址寻址
在基址+变址的基础上增加固定位移量（更灵活的数组访问）。  
格式：`操作码 目标, [基址寄存器 + 变址寄存器 + 位移量]`  
示例：  
```nasm
mov bx, 0x3000    ; 基址：数组起始地址
mov si, 1         ; 变址：索引
mov ax, [bx + si*2 + 0x10]  ; 地址 = 0x3000 + 1*2 + 0x10，访问该地址
```


### 四、程序结构
x86汇编程序通常按“段”（Section）划分，不同段负责不同功能（如数据存储、代码执行）。


#### 1. 常见段类型
- `.data`：数据段，定义常量、变量（程序运行中可修改）。  
- `.rodata`：只读数据段，定义不可修改的常量（如字符串）。  
- `.text`：代码段，存放可执行指令。  
- `.bss`：未初始化数据段，用于定义未赋值的变量（节省空间）。  


#### 2. 段定义与关联
用`section`伪指令定义段，用`assume`（仅16位汇编）关联段与寄存器（告诉汇编器哪个段对应哪个寄存器）。  

示例（32位汇编，NASM）：  
```nasm
section .data           ; 数据段
    num1 dd 100         ; 定义4字节变量num1=100
    num2 dd 200         ; 定义4字节变量num2=200

section .text           ; 代码段
    global _start       ; 声明程序入口
_start:                 ; 程序入口标签
    ; 代码逻辑...
```


### 五、常见指令分类与示例
汇编指令按功能可分为数据传送、算术运算、逻辑运算、控制转移等，以下是常用指令：


#### 1. 数据传送指令
用于在寄存器、内存、立即数之间传递数据。  
- `mov`：传送数据（注意：不能直接从内存到内存）。  
  示例：  
  ```nasm
  mov ax, 100       ; 立即数→寄存器（ax=100）
  mov [0x2000], ax  ; 寄存器→内存（内存0x2000处=ax）
  mov bx, [0x2000]  ; 内存→寄存器（bx=内存0x2000处的值）
  ```

- `push`/`pop`：栈操作（压栈/出栈）。  
  示例：  
  ```nasm
  push ax  ; 将ax的值压入栈顶
  pop bx   ; 将栈顶值弹出到bx（ax的值→bx）
  ```


#### 2. 算术运算指令
- `add`：加法（`add 目标, 源` → 目标 = 目标 + 源）。  
  示例：`add ax, bx`（ax = ax + bx）。  

- `sub`：减法（`sub 目标, 源` → 目标 = 目标 - 源）。  
  示例：`sub cx, 5`（cx = cx - 5）。  

- `mul`：无符号乘法（`mul 源` → 结果存放在`ax`/`dx:ax`中）。  
  示例：  
  ```nasm
  mov al, 5    ; al=5（8位乘数）
  mov bl, 3    ; bl=3（8位被乘数）
  mul bl       ; 结果=5*3=15，存放在ax中（ax=15）
  ```


#### 3. 逻辑运算指令
- `and`：按位与（`and 目标, 源` → 目标 = 目标 & 源）。  
  示例：`and ax, 0x0F`（保留ax的低4位，高12位清0）。  

- `or`：按位或（`or 目标, 源` → 目标 = 目标 | 源）。  
  示例：`or bx, 0x80`（将bx的最高位设为1）。  

- `not`：按位取反（`not 目标` → 目标 = ~目标）。  
  示例：`not cx`（cx的每一位取反）。  


#### 4. 控制转移指令
用于改变程序执行顺序（如分支、循环）。  
- `jmp`：无条件跳转（`jmp 标签`）。  
  示例：  
  ```nasm
  start:
      jmp loop  ; 无条件跳转到loop标签
  loop:
      ; 循环逻辑
  ```

- `je`/`jne`：条件跳转（相等/不相等时跳转，依赖标志位）。  
  示例：  
  ```nasm
  mov ax, 5
  mov bx, 5
  cmp ax, bx  ; 比较ax和bx（ax - bx，不保存结果，仅改标志位）
  je equal    ; 若ax == bx，跳转到equal
  jne not_equal ; 若ax != bx，跳转到not_equal
  equal:
      ; 相等时执行
  not_equal:
      ; 不相等时执行
  ```

- `call`/`ret`：函数调用与返回（`call 函数标签`调用函数，`ret`返回）。  
  示例：  
  ```nasm
  main:
      call add_num  ; 调用add_num函数
  add_num:
      ; 函数逻辑
      ret           ; 返回main
  ```


### 六、完整程序示例
以下是一个32位Linux下的汇编程序，功能：计算`num1 + num2`并输出结果（通过系统调用退出）。

```nasm
section .data           ; 数据段
    num1 dd 150         ; 定义变量num1=150（4字节）
    num2 dd 250         ; 定义变量num2=250（4字节）
    sum dd 0            ; 用于存储结果

section .text           ; 代码段
    global _start       ; 声明入口点（Linux要求）
_start:
    ; 计算sum = num1 + num2
    mov eax, [num1]     ; eax = num1（150）
    add eax, [num2]     ; eax = 150 + 250 = 400
    mov [sum], eax      ; sum = 400

    ; 退出程序（Linux系统调用：eax=1表示退出，ebx=0表示正常退出）
    mov eax, 1
    xor ebx, ebx        ; ebx=0（异或自身清0）
    int 0x80            ; 触发系统调用
```


### 总结
汇编语言语法的核心是**指令格式**、**操作数类型**、**寻址方式**和**程序结构**。由于依赖CPU架构，学习时需明确目标架构（如x86），并通过实际编程练习掌握指令和寻址方式的使用。
